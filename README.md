# Overlay Monster

Protected AI overlay browser built with Electron, React, and TypeScript.

## Structure

- `electron/` — Electron main process and preload boundary.
- `src/` — React renderer.
- `public/` — static renderer assets.
- `vite.config.ts` — renderer build configuration.
- `tsconfig.json` — renderer TypeScript configuration.
- `tsconfig.electron.json` — Electron TypeScript configuration.

## Development

```bash
npm install
npm run dev
```
